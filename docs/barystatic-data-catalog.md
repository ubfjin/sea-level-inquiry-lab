## 웹 공통 형식

원본 NetCDF는 성분별로 유지한다. `component_catalog.json`이 파일명과 성분별 변수명을 공통 키에 연결하며, 백엔드 어댑터가 다음 응답 형식으로 변환한다.

- 성분 목록: 자료 기간, 기준기간, 단위, 시간 처리 방법, 파일 연결 상태
- 시계열: `date`, `monthly_mm`, `moving_12m_mm`, `linear_trend_mm`, `quality`
- 지도: `requested_date`, `data_date`, `latitudes`, `longitudes`, `values`, `unit`

저장된 0°와 360° 경도는 같은 위치다. 웹 지도 응답에서는 중복된 360° 끝점을 제거해 0–359°의 360개 경도만 전달한다.

## 합계 원칙

성분 자료를 자동으로 모두 더하지 않는다. 합계를 제공할 때는 사용자가 명시적으로 선택한 성분과 모든 선택 성분이 동시에 존재하는 공통기간을 표시하고, 결과 이름도 `선택 성분 합계`로 제한한다. 이를 완전한 barystatic 총합으로 표현하지 않는다.
